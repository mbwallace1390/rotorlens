# RotorLens support

RotorLens is a community open-source project and does not provide guaranteed
response times or individualized flight-tuning services.

## Before opening an issue

1. Search the README, project documentation, existing issues, and closed
   issues.
2. Confirm the behavior on the latest official development build when it is
   safe to do so.
3. Reduce the problem to the smallest reproduction using committed or newly
   generated synthetic data.
4. Use the appropriate GitHub issue form.

For vulnerabilities, privacy bypasses, exposed secrets, or an issue that could
be exploited to produce unsafe advice, follow [SECURITY.md](SECURITY.md) rather
than opening a public issue. Conduct reports follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Never post private flight data

Do not attach, paste, commit, or link raw flight logs, configuration dumps, GPS
or home coordinates, timestamps, device or aircraft identifiers, serial
numbers, private paths or filenames, credentials, or personal data. Public
issue attachments and external file-sharing links are public disclosure, even
if the issue is later edited. Use synthetic fixtures.

## Safety

RotorLens output is evidence-limited guidance, not a guarantee that an aircraft
is safe to fly. Review changes against authoritative Rotorflight documentation,
change one thing at a time, keep a recoverable configuration backup off the
public issue tracker, and test conservatively. Stop using advice that conflicts
with observed aircraft behavior or qualified human judgment.

Unofficial forks and modified distributions are supported by their respective
publishers. See [TRADEMARKS.md](TRADEMARKS.md) for how official and unofficial
builds are distinguished.
